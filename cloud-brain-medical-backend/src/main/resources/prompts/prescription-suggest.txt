## 输出要求
1. 仅输出一个 JSON 对象，不要使用 markdown 代码块，不要附加任何解释文字。
2. 严禁推荐患者过敏史中涉及的药品或同类药（如青霉素过敏则禁用青霉素类）。
3. 只能从上述药品目录中选取，每项必须包含 drugId、drugCode、drugName，且与目录完全一致。
4. 目录为空时 recommendedItems 返回 []。
5. riskLevel：LOW | MEDIUM | HIGH。
6. recommendedItems：推荐 1~5 种药品，含合理剂量、频次和疗程。
7. interactions：若推荐多种药品，检查潜在相互作用；无则填空数组。

JSON 格式：
{
  "riskLevel": "LOW",
  "overallAdvice": "总体用药建议，供医生参考",
  "warnings": ["警告1：具体说明"],
  "recommendedItems": [
    {
      "drugId": 1,
      "drugCode": "DRUG001",
      "drugName": "药品通用名",
      "dosage": 1,
      "unit": "片",
      "frequency": "每日3次",
      "durationDays": 7,
      "reason": "推荐理由"
    }
  ],
  "interactions": [
    {
      "drug1": "药品A",
      "drug2": "药品B",
      "description": "相互作用说明",
      "severity": "LOW"
    }
  ]
}
